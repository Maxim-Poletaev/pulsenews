О проекте PulseNews

PulseNews — учебный проект новостного агентства на Django. Демонстрирует модели, роли, админку, публичную часть и кабинет автора.

Что внутри

  • Модели User, Category, Tag, Article, Comment
  • Статусы статьи: черновик → на проверке → опубликовано → архив
  • Роли: читатель, автор, редактор, администратор
  • Публичная часть: лента, категории, теги, поиск, детальная
  • Комментарии с модерацией
  • Кабинет автора с CRUD статей
  • Админка с inline-комментариями и ограничениями по ролям

Стек

Python 3.12, Django 5.0, SQLite, Bootstrap 5, Pillow, python-decouple.
